\resumeSubHeadingListStart


  \resumeProject
    {Visual SLAM Profiling and Latency Optimization}
    {VinDynamics}
    {August 2026}

  \resumeItemListStart
    \item Profiled the OKVIS2 visual SLAM pipeline and identified landmark matching and local-window optimization as major bottlenecks, taking approximately 20 ms and 40 ms respectively.

    \item Evaluated lower-latency front-end pose publishing, observing only 1.16 cm RMSE in translational APE relative to back-end poses.

    \item Redesigned frame scheduling to prioritize the latest available frame and drop stale frames, reducing average front-end latency from 124.00 ms to 47.00 ms and back-end latency from 164.30 ms to 87.64 ms.
  \resumeItemListEnd


  \resumeProject
    {Multi-Sensor Local Height Mapping for Humanoid Robot}
    {VinDynamics}
    {July 2026 -- August 2026}

  \resumeItemListStart
    \item Extended an existing LiDAR-based GPU height mapper to integrate Livox LiDAR and Intel RealSense depth data, implementing sensor synchronization, rate limiting, pose lookup, and robot self-filtering.

    \item Implemented and benchmarked pose extrapolation to compensate for SLAM latency; linear extrapolation reduced translational APE RMSE from 2.148 cm to 0.445 cm (79.3\%) for a 30 Hz depth camera.

    \item Deployed and validated the multi-sensor height mapping system on an in-house humanoid robot with calibrated LiDAR and depth camera data.
  \resumeItemListEnd


  \resumeProject

    {Rikai Mind}
    {August 2022 -- December 2022}
